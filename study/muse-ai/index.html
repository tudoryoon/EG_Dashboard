계산 구조·기본 가정: Muse Free-Tier Economics, 제작자 GDP (@bookwormengr). EG Dashboard는 해당 수학적 모델을 재구현했습니다. 입력 가정은 자동 최신화되지 않습니다.

  • Prefill 비중은 토큰 구분에만 사용됩니다. GPU 비용은 통합 tokens/$ 효율로 결정되며 Prefill 비중만 바꾸어도 비용은 변하지 않습니다.
  • tokens/$를 고정하면 GPU 시간당 TCO를 바꿔도 총 GPU 비용은 일정하고, 역산한 GPU 수·전력이 달라집니다. 원본의 같은 가정입니다.
  • 원본의 Break-even은 적자 탈출선이 아니라 기존 사용자당 이익액을 유지하는 데 필요한 추가 매출입니다. 이익률 유지 기준과 구분했습니다.
  • 1.70kW/GPU와 Prefill 97%는 원본의 역산·추정값입니다. CPU 전력, 세션 수, 할인율 등도 가정이며 검증된 실측값으로 간주하면 안 됩니다.
  • 벤치마크 수준의 캐시 재사용을 가정합니다. 네트워킹·모델 학습·인건비는 제외하며 Muse 이용자와 Meta 일간 이용자를 같은 모집단으로 취급합니다.
  • 물리 자원보다 많은 vCPU·RAM을 할당할 수 있다고 가정하며, 5가지 제약 중 최솟값으로 서버당 VM 수를 결정합니다. 실제 배치 보장이나 운영 권고는 아닙니다.
